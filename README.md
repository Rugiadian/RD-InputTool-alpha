# RD 오토 입력 툴 (Auto Input Tool)

지정한 문구를 원하는 화면 좌표에 마우스 클릭 후 자동으로 반복 입력하는 윈도우 데스크톱 자동화 도구입니다.

---

## 🚀 실행 방법

- `G:\Unity-Git\RD_Tools\Run_AutoInputTool.bat` 더블 클릭  
  또는  
- `G:\Unity-Git\RD_Tools\Publish\RD_AutoInputTool.exe` 직접 실행

---

## 📌 주요 기능 및 사용법

### 1. 원하는 문구 지정
- 텍스트 박스에 자동 입력할 문구를 입력합니다.
- **입력 후 Enter 키 전송**: 체크 시 문구를 입력한 뒤 자동으로 Enter 키를 누릅니다 (채팅, 커맨드, 폼 제출 등에 유용).
- **클립보드 붙여넣기 방식 (Ctrl+V)**: 한글, 이모지, 특수문자 깨짐 없이 100% 안정적으로 입력됩니다. (체크 해제 시 키보드 SendInput 유니코드 타이핑 방식 사용)

### 2. 클릭 포인트(좌표) 지정
- **🎯 클릭으로 좌표 지정** 버튼을 누르면:
  1. 화면 전체에 반투명 십자선 오버레이가 나타납니다.
  2. 원하는 입력 위치로 마우스를 옮긴 후 **마우스 좌클릭**하면 해당 좌표(X, Y)가 즉시 자동 등록됩니다.
  3. *(취소하려면 ESC 또는 마우스 우클릭)*
- **📍 현재 마우스 위치 (F8)**: 입력하려는 위치에 마우스를 올려둔 상태로 `F8` 키를 누르면 즉시 좌표가 등록됩니다.
- X, Y 좌표를 직접 숫자로 입력하여 미세 조정할 수도 있습니다.
- **클릭 후 대기 시간**: 마우스 클릭 후 창이 포커스를 잡을 때까지 기다리는 지연 시간 (기본 100ms).

### 3. 반복 간격 및 지속 시간 지정 (ON/OFF 토글 지원)
- **반복 간격**: 몇 초마다 한 번씩 입력할지 설정 (예: 1.0초, 0.5초 등, 0.05초~3600초 지원).
- **지속 시간 지정 (ON/OFF 토글)**:
  - 체크(ON) 시: 설정한 초(예: 10.0초) 동안 반복 후 자동 종료.
  - 체크 해제(OFF) 시: 시간 제한 없이 반복 (단독 해제 시 무제한 반복 모드로 동작).
- **반복 횟수 지정 (ON/OFF 토글)**:
  - 체크(ON) 시: 설정한 횟수(예: 10회) 입력 후 자동 종료.
  - 체크 해제(OFF) 시: 횟수 제한 없이 반복.
- **무제한 반복**: 시간과 횟수 제한 옵션을 모두 끄면(OFF) ESC를 누를 때까지 무제한으로 반복됩니다.

### 4. 긴급 중지 및 단축키
- **ESC 키**: **어느 창(메모장, 브라우저, 게임, Unity 등)에 있든 ESC 키를 누르면 매크로가 0.01초 내에 즉각 강제 중지**됩니다. (전역 저수준 키보드 훅 적용)
- **F7**: 작업 정지 (ESC와 동일하게 즉시 중지)
- **F8**: 현재 마우스 위치 좌표 즉시 캡처 (마우스를 원하는 곳에 올리고 F8 클릭)
- *(오작동 방지를 위해 '시작'은 창 내의 [▶ 시작] 버튼을 직접 클릭하여 기동합니다)*

### 5. 실시간 기동 상태 대시보드 및 에너지 바 (신규 추가!)
- **실시간 남은 정보 카드 표기**:
  - **🎯 남은 횟수**: `10회 남음` (횟수 제한 미사용 시 `무제한`)
  - **⏳ 남은 시간**: `6.4초`와 같이 소수점 단위 실시간 카운트다운 (시간 제한 미사용 시 `무제한`)
  - **📊 입력 완료**: 현재까지 총 몇 회 입력되었는지 실시간 집계
- **⚡ 실시간 기동 에너지 바 (Energy Bar)**:
  - 매크로가 멈추지 않고 살아있는지 한눈에 알 수 있도록 **다음 입력 시점까지 에너지가 차오르는 네온 그라데이션 애니메이션 게이지**를 제공합니다.
  - 에너지가 100% 충전되면 마우스 클릭 및 문구 입력이 실행된 후 다시 0%부터 충전을 시작합니다.
  - 애니메이션 셔 효과(Shimmer) 및 기동 뱃지(`🟢 기동 중 (RUNNING)`)로 작동 여부를 직관적으로 확인 가능합니다.
- **📈 전체 작업 진행률 바**: 설정된 목표(시간/횟수)에 도달하는 전체 진행률(%)을 표시합니다.

### 6. 기타 편의 기능
- **📌 창 항상 위에 고정 버튼 (창 맨 아래 위치)**: 
  - 조작하기 불편했던 작은 체크박스 대신, **창 맨 아래에 큼직하고 누르기 편한 대형 버튼**으로 변경되었습니다.
  - 클릭 한 번으로 `[ON] (파란색 활성)` / `[OFF] (회색 비활성)` 상태를 손쉽게 전환할 수 있습니다.
- **설정 자동 저장**: 입력 문구, 좌표, 간격, 시간, 항상 위 상태 등 마지막 설정값이 `auto_input_config.json`에 자동 저장되어 재실행 시 유지됩니다.

## 🛠 빌드 및 소스 코드
- `.NET 10.0 Windows Desktop (WinForms)` 기반으로 작성되었습니다.
- 소스 코드 수정 후 빌드:
  ```powershell
  dotnet build
  dotnet publish -c Release -o Publish
  ```

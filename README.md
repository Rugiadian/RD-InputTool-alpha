# RD 오토 입력 툴 (Auto Input Tool)

지정한 문구를 원하는 화면 좌표에 마우스 클릭 후 자동으로 반복 입력하는 윈도우 데스크톱 자동화 도구입니다.

---

## 🚀 실행 방법

- **`Run_AutoInputTool.bat` 더블 클릭 (권장)**:
  - 이미 프로그램이 켜져 있더라도 **자동으로 기존 창을 닫고**, 소스 코드 수정 내역을 **초고속 자동 빌드하여 최신 버전으로 재실행**합니다.
- **`Run_Dev_Watch.bat` 더블 클릭 (개발/실시간 반영 모드)**:
  - .NET Hot Reload 모드로 기동되어, **코드를 수정하고 저장(Ctrl+S)하기만 하면 앱을 껐다 켜지 않아도 실시간으로 반영/자동 재실행**됩니다.
- 또는 `Publish\RD_AutoInputTool.exe` 직접 실행

---

## 📌 주요 기능 및 사용법

### 1. UI 컬러 테마 선택 (4가지 제공)
- **우측 상단 테마 드롭다운**을 통해 취향과 환경에 맞는 컬러 테마를 선택할 수 있습니다.
  - 🍦 **아이보리 웜 (Ivory Warm)**: 부드럽고 따뜻한 린넨/아이보리 감성 (기본값)
  - 🌙 **모던 다크 (Modern Dark)**: 어두운 환경 및 야간 작업에 최적화된 고급 다크 테마
  - 🌊 **쿨 블루 (Cool Blue)**: 시원하고 세련된 인디고/스카이 블루 테마
  - 🌿 **세이지 그린 (Sage Green)**: 눈이 편안한 자연 친화적인 세이지 그린 테마
- 설정한 테마는 종료 후 재실행 시에도 자동 유지됩니다.

### 2. 원하는 문구 지정
- 텍스트 박스에 자동 입력할 문구를 입력합니다.
- **입력 후 Enter 키 전송**: 체크 시 문구를 입력한 뒤 자동으로 Enter 키를 누릅니다 (채팅, 커맨드, 폼 제출 등에 유용).
- **클립보드 붙여넣기 방식 (Ctrl+V)**: 한글, 이모지, 특수문자 깨짐 없이 100% 안정적으로 입력됩니다. (체크 해제 시 키보드 SendInput 유니코드 타이핑 방식 사용)
- **포인트 2 별도 문구 지정**: 2개 포인트 모드 사용 시 포인트 2에 다른 문구를 입력하도록 지정할 수 있습니다 (미체크 시 동일 문구 입력).

### 3. 클릭 포인트(좌표) 지정 (2개 포인트 옵션 지원)
- **입력 포인트 2개로 확장**:
  - 체크 시 포인트 1(P1)과 포인트 2(P2)를 등록하여 **1초 간격(조정 가능)으로 순차 입력**합니다.
  - P1 클릭 및 입력 ➔ 1초 대기 ➔ P2 클릭 및 입력 ➔ 다음 반복 주기로 진행됩니다.
- **🎯 클릭으로 좌표 지정**:
  1. 화면 전체에 반투명 십자선 오버레이가 나타납니다.
  2. 원하는 입력 위치로 마우스를 옮긴 후 **마우스 좌클릭**하면 해당 좌표(X, Y)가 즉시 자동 등록됩니다.
  3. *(취소하려면 ESC 또는 마우스 우클릭)*
- **📍 현재 위치 등록**: 마우스가 있는 좌표(X, Y)를 즉시 등록합니다.
- X, Y 좌표를 직접 숫자로 입력하여 미세 조정할 수도 있습니다.
- **클릭 후 대기 시간**: 마우스 클릭 후 창이 포커스를 잡을 때까지 기다리는 지연 시간 (기본 100ms).

### 4. 반복 간격, 시작 대기 및 지속 시간 지정 (초/분/시간 단위 선택)
- **시작 대기 시간**:
  - **바로 시작 (0초)**: 시작 버튼 클릭 즉시 카운트다운 없이 바로 입력 시작.
  - **대기 후 시작 (n초 후 시작)**: 원하는 초(예: 2.0초, 3.0초 등) 동안 실시간 카운트다운 후 입력 시작.
- **반복 간격 (단위 선택 지원)**:
  - **초 / 분 / 시간** 선택 가능 (기본값: **초**).
  - 예: 1.0초 마다, 5분 마다, 1시간 마다 등 유연하게 반복 설정 가능.
- **지속 시간 지정 (ON/OFF 토글 & 단위 선택 지원)**:
  - **초 / 분 / 시간** 선택 가능 (기본값: **초**).
  - 체크(ON) 시: 설정한 시간(예: 10초, 30분, 2시간 등) 동안 반복 후 안전하게 자동 완료.
  - 체크 해제(OFF) 시: 시간 제한 없이 계속 동작.
- **반복 횟수 지정 (ON/OFF 토글)**:
  - 체크(ON) 시: 설정한 횟수(예: 10회) 입력 후 자동 완료.
  - 체크 해제(OFF) 시: 횟수 제한 없이 반복.
- **무제한 반복**: 시간과 횟수 제한 옵션을 모두 끄면(OFF) 중지 단축키 또는 정지 버튼을 누를 때까지 무제한으로 반복됩니다.

### 5. 단축키 사용자 지정 및 긴급탈출 (Alt+F4)
- **단축키 사용자 지정 기능 (깔끔한 드롭다운 방식)**:
  - **시작 단축키 (기본값: `Alt + F1`)**: 전역 단축키로 어디서든 즉시 자동 입력 기동.
  - **정지 단축키 (기본값: `F2`)**: 작업 중 즉시 정지 및 루프 초기화.
  - **🚨 긴급탈출 단축키 (기본값: `Alt + F4`)**: 비상 상황 시 강제 비상 탈출/즉각 중지.
- **직관적인 드롭다운 설정**:
  - 복잡한 팝업 감지 버튼 없이, **조합키(없음, Alt, Ctrl, Shift, 조합키 등)**와 **키(F1~F12, 숫자, 알파벳 등)**를 드롭다운으로 간편하게 즉시 선택.
  - **실시간 반영 및 자동 저장**: 단축키를 변경하는 즉시 UI 버튼 문구, 안내 배너, 대시보드에 실시간 반영되며 영구 저장됩니다.
  - **🔄 기본값 복원**: `[🔄 기본값]` 버튼으로 언제든 표준 설정(시작: `Alt+F1`, 정지: `F2`, 긴급탈출: `Alt+F4`)으로 즉시 복원 가능.
- **🚨 긴급탈출 보호 메커니즘**:
  - **단축키 비활성화 상태(OFF)이더라도 긴급탈출(`Alt + F4`)은 항상 동작**합니다.
  - 실행 중 `Alt + F4`가 입력되면 매크로만 즉시 안전하게 중단하고, 대상 애플리케이션 창이 실수로 닫히지 않도록 키 입력을 스마트하게 가로채 보호합니다.
- **⌨ 단축키 온/오프 버튼 (하단 바 위치)**:
  - `[항상 위 고정]` 버튼 옆에 **단축키 ON/OFF 전환 버튼**이 배치되어 있습니다.
  - 프로그램 실행 시 기본값으로 단축키가 항상 활성화(ON) 상태로 기동되어 바로 사용할 수 있습니다.
  - 비활성화 시 버튼 표시: **`단축키 비활성 중. 긴급탈출 {지정한 긴급탈출키}`** (기본값: `Alt + F4`)
  - 일반 작업 시 오작동을 차단하면서도, 비상시에는 언제든 긴급탈출 키로 즉각 매크로를 정지시킬 수 있습니다.

### 6. 실시간 기동 상태 대시보드 및 루프 자동 초기화
- **심플하고 직관적인 대시보드 구조**:
  - 불필요한 중복 뱃지와 진행률 바를 제거하고, **핵심 상태 카드 3종 + 실시간 에너지 바 + 상태 안내**로 깔끔하게 정돈되었습니다.
- **실시간 남은 정보 카드 표기**:
  - **🎯 남은 횟수**: `10회` (횟수 제한 미사용 시 `무제한`)
  - **⏳ 남은 시간**: `6.4초` / `2.5분` / `1.20시간` 실시간 카운트다운 (시간 제한 미사용 시 `무제한`)
  - **📊 입력 완료**: 현재까지 총 몇 회 입력되었는지 실시간 집계
- **⚡ 실시간 기동 에너지 바 (Energy Bar)**:
  - 다음 입력 시점까지 에너지가 차오르는 네온 그라데이션 애니메이션 게이지 제공.
  - 분/시간 단위 설정 시 남은 시간도 에너지 바에 표시됩니다.
- **🔄 작업 정지 시 루프 초기화**:
  - 작업 정지(F2, Alt+F2, 정지 버튼) 또는 완료 시 중단 시점의 남은 수치에 머무르지 않고, **설정한 목표값(0회 완료, 초기 횟수/시간)으로 즉시 루프가 리셋**되어 다음 작업 시 처음부터 깨끗하게 시작됩니다.

### 7. 하단 바 편의 기능 및 자동 저장
- **📌 창 항상 위 고정 버튼**: 창 맨 아래에서 클릭 한 번으로 `[ON]` / `[OFF]` 전환.
- **⌨ 단축키 활성/비활성 버튼**: 하단에서 클릭 한 번으로 단축키 `[ON]` / `[OFF]` 전환.
- **설정 자동 저장**: 입력 문구, 좌표, 2포인트 설정, 반복 간격/단위, 지속 시간/단위, 테마, 항상 위, 단축키 사용 여부 등 모든 설정이 `auto_input_config.json`에 영구 저장됩니다.
